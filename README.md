A one-star review written by a house cat about its human: breakfast served late, then the human eats his own food at the cat's table as if he pays the rent. Deadpan review shape, one specific complaint, sting in the last words — for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the single-line review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`). Python 3.13, standard library only, deterministic.
